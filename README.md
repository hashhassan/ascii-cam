# ASCII Cam

A fun web-based ASCII camera that converts your webcam feed into ASCII art in real-time.

## Live Demo
[View Live Project]()  
*(Deployed on AWS Amplify)*

## Features
- Real-time webcam to ASCII conversion
- Built with pure HTML, CSS & JavaScript
- No backend required

## Technologies Used
- HTML5
- CSS3
- JavaScript (Canvas API)

## How to Run Locally
1. Clone the repo
2. Open `index.html` in your browser
3. Allow camera permission
